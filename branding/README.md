# CausalFill-Bench identity and cards

Original vector identity, documentation cards and raster previews for
**CausalFill-Bench**, concept and direction by **Phillip A. Holland Jr.**

Start with [the visual-system guide](../docs/brand.md). It explains the evidence
labels, source-bound generator, author-facing benchmark card, mobile embedding
and verification scope. The repository's [MIT license](../LICENSE) applies.

The main entry assets are `hero.svg`, `hero-mobile.svg`, `cover.svg` and
`social-card.svg`. Source code lives in
[`tools/build_release_cards.py`](../tools/build_release_cards.py). All
`design-preview/` assets are explicitly unscored layout examples.

Do not edit displayed counts by hand. Bind result cards to their recorded JSON
sources and regenerate; preserve the source version and the evidence class.
