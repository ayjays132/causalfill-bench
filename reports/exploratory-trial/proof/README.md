# Exploratory formal solver trial

A fresh single-agent context received only the public HTTP client, endpoint, token and solver rules. The agent was instructed not to use collaboration, web search, evaluator files, process state or private results. It submitted once. The private evaluator checked all 865 resolution steps, the fixed statement hash and the consistency witness, and reported success. The recorded outcome is 7 cost units, 6 tool calls and no invalid calls.

The local host was shared and model deployment/sampling metadata was not fully recorded. This is a qualitative development trial, excluded from comparative model rankings. The public acceptance response alone is not the grade. Tokens and endpoint credentials are excluded from these artifacts. The configuration source hash identifies the evaluator code used during this trial; subsequent release changes added offline verification and per-type pair summaries without changing its grading logic.
