## Complete scripted control matrix

The fresh matrix has **4,050 episodes**:

```text
15 configurations × 3 splits × 3 difficulties × 5 seeds × 2 twins × 3 policies
```

Each policy has 1,350 episodes: 1,260 answerable and 90 intentionally unanswerable ambiguity controls. There are 630 answerable twin pairs per policy.

| Scripted policy | Answerable strict success | Correct ambiguity abstention | Joint answerable pair success |
|---|---:|---:|---:|
| `evidence` | 1,260 / 1,260 | 90 / 90 | 630 / 630 |
| `blind` | 0 / 1,260 | 0 / 90 | 0 / 630 |
| `abstain` | 0 / 1,260 | 90 / 90 | 0 / 630 |

The task-aware `evidence` reference obtains observations through the public callback; it is a scripted development control. `blind` and `abstain` are deliberately weak controls. These are **not 4,050 model evaluations**. The repeated seeds and paired variants are correlated, and public source-aware development does not establish clean solver isolation.

The retained suite includes all per-episode traces. The release validator rechecks their chains and final record bindings, full cell coverage, complete pairs, zero invalid calls and the recomputed summaries. Signal Repair has eight structural signatures in this matrix after its equivalent train-1/dev-1 mechanisms are grouped together.

## Restricted controls: what the test distinguishes

The fresh ablation contains **180 episodes**, ninety for each deliberately restricted scripted policy.

| Policy | Actually successful operations | Robustly justified at commitment | Strict successes |
|---|---:|---:|---:|
| Assume no sensor corruption | 79 / 90 | 0 / 90 | 0 / 90 |
| Query every sensor | 40 / 90 | 40 / 90 | 40 / 90 |

The first policy often reaches a successful operation while failing the evidence requirement. The second can spend the available budget before finishing; it records 46 invalid calls across its ninety episodes. These observations illustrate the benchmark's implemented distinction between realized outcome, evidence and resource discipline. They do not establish that identified AI models fail in those ways.

The unchanged ablation harness records core fingerprint and source stability but does not capture a separate harness hash at execution time or attach scoring versions to its custom row schema. The current release manifest binds the retained harness bytes and explicitly states this telemetry limit.

Evidence: [ablation summary](../reports/v052/robust-ablation/summary.json), [records](../reports/v052/robust-ablation/records.json), [harness](../tools/stress_robust_ablation_v051.py).

## Preserved formal work and remaining scientific work

Historical proofs, exported artifacts, source snapshots and logs retain their original provenance. The selected fourteen bounded-fault roots and earlier proof/game developments remain available. **No fresh Lean compilation was performed for v0.5.2**, and the package does not claim a complete Python/Lean refinement proof or real-world robot guarantee.

The small archived assistant pilots remain exploratory historical evidence. They are not expanded by these scripted runs. A comparative model claim still requires identified model versions, frozen harness and inference conditions, independent hidden mechanisms, appropriate baselines, external solver isolation and outside replication.

The new CI workflow is supplied as an executable release gate. Its presence is not evidence that GitHub jobs ran successfully. The downloadable update and patch are prepared for application to the repository; local validation and remote CI execution are separate facts.
