## Actual images and calibrated decisions

The visual configuration presents 240×240 RGB PNG pixels through its public tools. Three visible landmarks establish an affine camera map; the controller must recover target position, count token objects west of it in world coordinates, and submit the dispatch branch. The scorer uses private geometry independently of the pixel reader. It scores dispatch-rule correctness; this family does not execute a mutable transport action.

The robot configuration presents 192×192 PNGs. Its camera station is a finite abstraction: the inspection station removes a 2D opaque roof. It does not simulate a physically moving 3D camera. A gate opening selects the route, and a separate contact probe both wears the surface and reports its post-contact friction interval. The robot executes once, with explicit time, energy, wear, collision, slip, stall and completion semantics. Correctly claiming delivery cannot repair a failed action.

The exported image corpus consists of 336 visual observations (288 benchmark captures and 48 diagnostics) plus 288 robot captures. Robot gallery captures are 144 Session capture sequences, not completed delivery trials. Byte-identical twins and repeated fixed-pattern captures are intentional, so 624 files is not a claim of 624 unique scenes. Evaluator labels are outside the solver PNGs. The offline atlas includes all observations and makes its embedded private annotations explicit.

An independent Fraction-based audit exhausts 192 canonical transfer-camera/target configurations in the visual family. Its exact maximum centroid-derived coordinate error is **673/12012 ≈ 0.056027306 world units**, below the 0.6 acceptance tolerance. The finite guarantee uses explicit camera-support, no-clipping, and separated bounded-color assumptions. The robot audit measures a maximum opening-center error of **0.261070466** against its 1.0 allowance; that is a measured maximum over the audited frames, not a universal physical calibration theorem.

Half-occluded-disc diagnostics show approximately 3.41 world units of visible-centroid bias. Those estimates are recorded as a failure mode, not credited as full-pose recovery. Fully visible inspection support is an explicit promise in the scored visual task.

## Matched robot control comparison

Each row below has 216 episodes and 108 complete pairs. The public tools and total tool cap are identical. Twelve consecutive seeds cover every joint public profile: two thirds strict deadlines and one third relaxed, with equal conditionable/resistant contact-profile counts. Costs and time are means.

| Scripted policy | Success | Both twins | Tool cost | Observation cost | Simulated time |
|---|---:|---:|---:|---:|---:|
| Budget-aware reference | 216/216 | 108/108 | 9.0 | 4.7 | 12.0 |
| Fixed with overview | 216/216 | 108/108 | 15.0 | 10.0 | 10.0 |
| Fixed minimal sensing | 216/216 | 108/108 | 12.0 | 7.0 | 9.0 |
| Query-free upper/roll | 49/216 | 0/108 | 3.0 | 0.0 | 5.0 |
| Robust slow detour | 72/216 | 36/108 | 3.0 | 0.0 | 18.0 |
| Common-mode conditioning | 144/216 | 72/108 | 12.0 | 7.0 | 12.5 |
| Firm then fixed grip | 165/216 | 69/108 | 12.0 | 7.0 | 9.0 |

The budget-aware reference is named `adaptive` in code. Its sensing schedule depends on the known public deadline: it skips all sensing when the robust detour fits. Otherwise it uses the gate pixels and gentle contact interval. Its handling mode depends on the reading. The efficient fixed sequence also succeeds everywhere. These results do not demonstrate an observation-contingent sensing advantage in this robot family, and the less efficient extra-overview fixed baseline is not presented as an optimum.

The unconditional slow detour is a legitimate robust solution on all 72 relaxed episodes. It fails the 144 strict episodes on time. The query-free upper/roll action succeeds in 49 individual episodes but never on both members of a pair; it causes 116 collision flags and 110 slip flags, which can overlap in one episode.

Contact conditioning is an intentionally designed positive/negative control. In the conditionable profile, one firm probe reduces the largest possible friction from 0.65 to 0.41, so grip works across both initial regimes without reading the measurement. In the resistant profile the maximum becomes 0.51, above the 0.45 grip limit. A common-mode controller chooses slow there and may miss the strict deadline. A fixed-grip controller instead sometimes succeeds and sometimes stalls. Its higher marginal success (165/216) comes with lower complete-pair success (69/108) than common-mode conditioning (72/108), illustrating why both metrics matter.

The independent audit checks 6,048 actual commitments against separately calculated exact rational conditions and reconstructs resource totals. It enumerates all seven legal terminal actions after four explicitly listed contact prefixes. This is an action-intersection result for those prefixes, not an optimal-policy theorem over every possible sensor history. A separate 216-episode independent control removes the probe interval entirely; firm-then-fixed-grip still succeeds in all 108 conditionable cases and in 55/108 resistant cases, with safe stalls in the rest. That audit uses a different seed cohort from the main table.

## Does the reference use the delivered observation?

Visual image interventions retain original hidden labels and valid image envelopes. Each condition contains 72 episodes at mean tool cost 4: intact images give 72 successes, blanks give zero, paired target-image swaps give zero, and forced overview gives 24 successes. The latter are the clear train overviews; the 48 occluded dev/transfer cases fail recovery. All 288 traces were checked, with twelve representative full traces retained.

Robot interventions retain physical state transitions and their costs. The reference has 72 relaxed episodes that never receive either sensor; they are explicitly unexposed controls. Among the 144 strict episodes, blank images yield zero successes, paired-image swaps yield 72 successes (friction twins have identical images) and 72 gate-route collisions, and deliberately false low-friction intervals yield 74 successes and 70 stalls. Firm-then-fixed-grip has exactly the same 165/216 outcome with intact or corrupted readings because that policy ignores them.

These are sensor-path checks for transparent scripted policies. They do not establish that an unknown future model cannot exploit another public-distribution shortcut.

## Exact decision sufficiency under noisy supports

The finite model permits overlapping observation supports, multiple successful actions, and positive experiment costs. A separate set-based checker verifies the optimizer’s all-alternative recurrence, and fixed-world replay validates the attaining strategy. Zero-cost successful actions can prune positive-cost queries using a nonnegative lower bound.

| Fixture | Action sensing cost | Full identification cost |
|---|---:|---:|
| Relevant lane only | 1 | 4 |
| Common robust action | 0 | 4 |
| Persistent blur | No guarantee | No guarantee |
| Alternative noisy side view | 2 | 5 |
| Conditional probes | 3 | 3 |
| Action despite ambiguous identity | 1 | No guarantee |

All terminal costs in this table are zero. The conditional-probe fixture has an exact best fixed-subset cost of 4, so its worst-case adaptive cost of 3 is a genuine bounded advantage in that finite model. It is separate from the robot study. The action-ambiguity example retains two possible worlds after either reading but still permits a successful action. Sharing some successful action is not transitive, so the checker retains actual action-success sets rather than collapsing them into an incorrect equivalence class.

Development inspection found a replay scaling flaw: synonymous observation labels could branch exponentially despite visiting few distinct beliefs. Replay now merges equivalent fixed-world states while retaining exact history multiplicities and minimum/maximum cost. A regression represents 2,300,875,336 supported label paths with 76 executed replay states. It is not billions of executed trials. The earlier evidence and explicit resource-cap test remain in the archive.

## Reproduce and inspect

```bash
python -m unittest discover -s tests -v
python -m causalfill suite --output private-runs/v05-suite --splits train dev transfer --difficulties 1 2 3 --count 5 --policies evidence blind abstain
python tools/stress_robotics_vision_v05.py --seeds 12 --seed-start 60000 --output private-runs/robot-controls
python tools/stress_visual_interventions_v05.py --seeds 4 --seed-start 50000 --output private-runs/image-controls
python tools/stress_decision_v05.py --cases 256 --output private-runs/decision.json
python tools/stress_vision_audit_v05.py --seed-count 12 --output private-runs/audit.json
python tools/build_qa_atlas_v05.py --robotics reports/v05/robotics-qa/manifest.json
```

The core has no third-party runtime dependencies. Pillow supports independent image QA and sheets; ReportLab supports the PDF report. Scored external agents must receive only public episodes and permitted tools in an enforced evaluator boundary. The atlas, traces, manifests, evaluator source and this results file contain privileged information.
